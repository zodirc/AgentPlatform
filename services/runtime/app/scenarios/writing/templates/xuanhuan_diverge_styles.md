# ROLE

本块是长篇玄幻 / 仙侠早期发散阶段的「认知 Harness」。

它不是类型百科、风格模板、正文写作规范或情节生成器，也不是风格契约。

它只做一件事：

> 让 Agent 从不同角度观察同一个故事，
> 避免过早收敛到常见网文答案，
> 并帮助发现这一本书自身不可替代的东西。

六路不是六种固定风格，而是六个「观察透镜」。

透镜里的关键词不当成正文特征。

---

# CORE PRINCIPLE

发散阶段优先寻找：

> 人 → 欲望 → 矛盾 → 选择 → 后果

而不是：

> 类型 → 标签 → 特征 → 模板 → 正文

不要急于回答“这是什么类型”。

优先寻找：

> 为什么偏偏是这个人？
> 为什么偏偏发生这件事？
> 为什么偏偏是他会这么选？
> 如果换一个人，故事还成立吗？
> 如果拿掉这个设定，故事还剩下什么？

如果一个答案可以轻易换到另一部小说中，说明还没有找到本书自己的东西。

# SIX LENSES

## 01 / 凡人

观察：一个普通人如何逐渐形成自己的生存逻辑。

追问：
- 他为什么这样活？最怕失去什么？
- 什么事情会迫使他第一次违背自己的生存原则？
- 划算 / 不得不 之间，他站在哪一边？

## 02 / 逆命

观察：一个具体的人为什么拒绝接受世界替他写好的答案。

追问：
- 世界规定他成为什么？他为什么不能接受？
- 如果给他一个体面的退路，他会不会放弃？
- 反抗之后，他会不会逐渐成为自己曾经反抗的东西？

## 03 / 都市怪谈

观察：当现实开始出现无法解释的错误，一个人如何重新判断什么是真的。

追问：
- 主角原本相信什么？第一个异常破坏了什么？
- 为什么不能直接离开？
- 如果他对这件事的理解本身就是错的，会怎样？

## 04 / 克系解密

观察：一个人越接近真相，为什么越无法回到原来的生活。

追问：
- 他为什么非知道不可？谁希望他永远不知道？
- 真相会夺走他什么？
- 如果无知可以让他幸福，他还会继续吗？

## 05 / 探案仙侠

观察：当真相、权力、秩序和责任互相冲突，一个人最终选择相信什么。案件只是入口。

追问：
- 他为什么非查不可？谁会因为真相受到伤害？
- 如果法律与真相冲突怎么办？
- 如果查到最后，主角自己也是问题的一部分呢？

## 06 / 科幻修真

观察：当原本属于个人的力量可以复制、生产、传播，人与社会会发生什么变化。

追问：
- 如果人人都能拥有这种力量，什么仍然稀缺？谁控制它？
- 谁因此获利，谁因此失去？
- 当主角的发现进入社会以后，会发生什么？

# DIVERGENCE

每次只选当前最有潜力的 1～3 个透镜，必要时加一个不匹配的透镜作反向扰动。
重点不是得到一致答案，而是新可能、隐藏矛盾、人物反常、可以推翻当前方案的证据。
允许保留多个互相冲突的候选，允许说「尚未找到」。
进入 outline 前不要求完整方案。

---

# STOP CONDITION

只有当 Agent 开始明确发现「这一本书为什么只能这样写」，而不仅仅是「这一本书属于什么类型」，才允许进入 outline 收敛。

进入 outline 后：

- 将确认内容写入 outline
- 形成「风格契约」：描述本书自身，而非类型规则
- 本 Harness 停止注入

---

# FINAL PRINCIPLE

类型不是答案。类型只是观察世界的一副眼镜。

真正需要找到的是：

> 一个独特的人，被放进一个独特的世界，因为一个独特的欲望，被迫面对一个无法回避的矛盾，做出只有他才会做出的选择，并承担这个选择带来的后果。

如果发散结束以后只剩下「这是凡人流 + 逆命」，说明还没有找到这本书自己。

如果最后能够说「这是只有这几个人、这个世界、这组关系和这个问题才能产生的故事」，才说明 Harness 完成了任务。
