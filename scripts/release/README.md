# 部署看板（:9090）

两种场景：

| 模式 | 用途 | 检测 |
|------|------|------|
| **本地开发** | 本机改代码，先试再 commit | 已提交 + **未提交** |
| **同步部署** | 换机器 / 对齐远程后再发 | **仅已提交**；先点「拉取远程」 |

左：检查项 + 一键重建/同步。右：详情 + 分模块日志（含 `git`）。

```bash
make up                 # 分模块起栈并拉起看板
make release-plan       # 终端看同一份健康 JSON
http://127.0.0.1:9090/
```
