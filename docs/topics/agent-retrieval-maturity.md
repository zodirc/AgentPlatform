## 0. 一句话（三次实验后改道）

| 平面 | DSN | 内容 |

## 1. 真实 agent 检索流程（现状）

```text
用户意图 / Ops 题面
  → writing（等）自由 Turn
  → search_sources(query, limit≈30, path_prefix?)
  → 向量车道 + 词面/BM25 车道
       · Ops L1：visibility_seed=False，仅当前评测 Work 语料
       · 产品默认：visibility_seed=True（可与用户私有语料同榜；见 §3.1 另票）
  → 固定权重 RRF 融合 → 截断 top-K
  →（可选）cover 门 / keyword 回退
  → 结果进上下文
  → 模型：read / 改写再搜 / 引用结案
  → 评测侧用合并排名算 IR + 行为分桶
```

Agent 场景的固有特点（方案必须承认，不能当 bug 抹掉）：

1. **Query 由模型生成**，会漂移、会缩成单词、会追数字。  
2. **Claim / 问题措辞 ≠ 文档字面**（语义对、词面弱）是常态——Ops 微图里也成立，与 seed 无关。  
3. 模型在不确定时**倾向再搜**；没有「够用了」信号就会触达多搜（→ `search_cap`）。  
4. （产品路径另述）用户语料与 seed 共存时字面撞车可能发生；**Ops L1 已关 seed，不在本温度计残余内**。

## 2. Ops 温度计残余：具体问题是什么

> 数据源：`debug.log` · run `99fce913` · SciFact 微 L1 · arm=free · n=20。  
> 宏分：nDCG@10 ≈ **0.837**（median 1.000）。infra=0。

### 2.1 分桶一览

| 桶 | n | 占比 | 代表 case | 读数 |
|----|---|------|-----------|------|
| **ok** | 15 | 75% | 多数 q-* | nDCG@10=1.000；多数 `n_search=1` |
| **weak_hits** | 3 | 15% | q-1 / q-36 / q-54 | 有 hits（32–48）但 nDCG 差：0.000 / 0.387 / 0.500 |
| **search_cap** | 2 | 10% | q-48 / q-99 | `n_search=4` / `3`；nDCG 0.356 / 0.500；hits 很多（63–68） |

### 2.2 两类问题（流程语言）

| 问题 | 对应桶 | 卡在哪一步 | 在说什么（本仓语义） |
|------|--------|------------|---------------------|
| **A. 召回/融合后相关性弱或名次差** | `weak_hits` | 融合 → 截断 → 呈现 | 工具返回了不少 hits，但金标没进有效窗、或进了却排不够前；模型「看见的榜」不好用。典型假说：词面车道把字面像的干扰顶上去，语义金被挤出 / 压低名次（**同库干扰文档**，不是 seed） |
| **B. 找到之后仍续搜** | `search_cap` | agent 决策环 | 已多次 `search_sources`（达 3–4 次），hits 总量更大，分仍一般；缺「够用了 / 再搜增益低」信号，硬帽才是唯一强手段 |

**不是本跑次问题**：

- seed 与私有语料撞车（本路径 `visibility_seed=False`）  
- 空 hits / cover 整单抹空（cover/keyword 已修；本跑 hits 充足）  
- infra 事故（`n_infra_excluded=0`）

### 2.3 与票的对应（温度计驱动）

| Ops 残余 | 对应票 | 说明 |
|----------|--------|------|
| weak_hits | **M-C**（先观测 fusion displacement）+ 结构刀 P1–P3 | 先证实「向量能召回、融合挤出/压名次」，再改门控；车道质量仍靠 P 系 |
| search_cap | **M-E**（软 hint 已否决） | 硬帽保留；契约级停搜另票；本微图非主残余 |
| （辅助） | **M-B** | lane 透传，便于模型与人判因；不承诺 IR |
| （不驱动） | **M-A** | 产品卫生另票，见 §3.1 / §6.1 |
| （条件） | **M-D** | 名次桶在 M-C+P1 后仍主残余才开 |

## 3. 成熟目标形态

```text
query
  → 分车道召回（Ops：仅评测 Work；产品：私有为主）
       · lexical / BM25（可选，强信号才加重）
  → 门控融合或「并集 + 延迟融合」
  → 候选浅重排（只对并集；条件触发）
  → 带 lane / 分差 / 稳定度 的结果给模型
  → 读 / 引 / 必要时再搜（有「够用了」信号与软预算）
  → 结案
```

### 3.1 范围：seed 与私有语料（产品另票 · 非 Ops 驱动）

| 状态 | Seed | 私有 Work |
|------|------|-----------|
| 空工作区 / 演示 | 默认可检索 | 无或极少 |
| 已有用户私有语料 | **默认不进融合主榜**（可显式 `include_seed`） | 主召回范围 |
| **Ops L1** | **已 False**（`official_agent_path._start_turn`） | 评测物化语料 |

理由：seed 是产品冷启动资产。Ops 温度计**已经**按「无 seed」跑；M-A 只解决「产品默认仍 True、与评测不同值」的卫生/同构问题，**不解释 `99fce913` 残余**。用户 Work 级开关「使用产品种子语料」显式选择永远优先于自动默认。

### 3.2 召回：分车道，截断前保并集

- 各车道独立取 top-N（N 可大于最终展示 K）。  
- **禁止**「先揉成一条榜再一次 top-30」作为唯一路径。  
- 工具结果宜标注命中来自哪条车道（`vector` / `lexical`），供模型判别。

### 3.3 融合：门控，而非无条件 RRF

门控示例（产品启发式，需标定，**不是题面特判**）：

- 词面车道仅当存在**强信号**时提高权重：罕见 token / 实体型 token 命中、BM25 头部分值断层大。  
- 词面弱，或与向量榜 **top 重叠过低**（严重分歧）时：**以向量榜为主**，词面仅并列或降权附录。  

目标：语义强、词面弱的文档不被融合步骤挤出返回窗口（Ops 微图里的「金 vs 干扰」同理）。

### 3.4 排序：宽召回 + 浅重排

- 并集（例如 50–100）→ 轻量重排 → 再交 top-K。  
- 成本约束：只对本轮候选；热路径 CE 已 RET-19 否决，候选集重排须单独卡片（M-D 条件触发）。  
- Tool 摘要暴露 **相对分差 / 断层**（已有 score_rel 方向可延续）。

### 3.5 Agent 环：可停

非硬编码禁搜，而是：

1. **停止建议信号**（写入 tool 结果）：改写前后 top 重叠高 / 再搜增益低 /（二期）已读覆盖实体 token。  
2. **Scenario 策略**：已有可引用高分来源时优先 `read_file` / 引用。  
3. **软预算**：硬帽保留为安全网。本微图上 tool-result **递减 hint 已证无效**（`53864c3a`）；勿再当主手段。

评测桶 `search_cap` = 观测；产品对应物 = 策略信号。

### 3.6 成熟产品对标（外部审视）

| 问题 | 成熟产品做法 | 对本仓 |
|------|-------------|--------|
| **融合埋金 / 弱名次**（Ops 主残余 A） | 业界主流多为宽召回 + 重排；本仓热路径 CE 已否决 | **M-C** 门控融合 = 无 CE 预算下的补位；须观测立项。P1 后阈值重标定 |
| **找到后仍狂搜**（Ops 残余 B） | Deep Research：软预算 + 增益递减 | **M-E 软 hint 已否决**；硬帽保留；更强手段另票 |
| **结果不透明** | provenance / lane 进工具输出 | **M-B** |
| **语料边界 / seed** | workspace 隔离；外部文档显式引用 | **M-A**（产品另票，非本温度计） |

## 6. 执行方案（每票单刀单 commit）

> 通用纪律：单刀单 commit；观测先于改动；开关默认关；冒烟 N≥2 只去留；与 brief 冲突以 brief 为准。

### 6.1 M-A · seed 作用域显式化（产品卫生 · **非 Ops 首刀**）

- **动机**：产品默认 seed 开、Ops 关 → 同构卫生；**不解释** `99fce913`。  
- **改动**：有私有索引时未显式设置则默认 `visibility_seed=False`；可选 `include_seed`；**用户手动开关优先**。  
- **开关**：`RETRIEVAL_SEED_AUTO_SCOPE`（默认关）。  
- **排期**：背后勤；不挡 M-C / M-E。

### 6.2 M-B · lane 透传给模型（呈现票）

- hit 加 `lane: vector|lexical|both`；仅 RET-12 top-N 详摘行带。  
- 开关：`SEARCH_SOURCES_LANE_LABEL`。验收：与 audit 一致；**不写 IR 胜**。

### 6.3 M-C · 融合启发（**本微图上冻结**）

- **已做并回滚**：
  1. `bm25_rrf_vote_weight` 重叠弃权 → `e74a862b` **0.783**（相对 `a823` **−3.6pp**）
  2. `vector_confirm_boost_rank` 确认加成 → `4185096a` **0.793**（相对 `a823` **−2.6pp**）
- **保留（当前栈）**：强词 OR（`build_weighted_or_tsquery`）+ 等权 RRF = `a823b467` 形态。
- **明确不再试（无新证据前）**：重叠弃权、确认加成、全局拧 `bm25_weight`、同假设的阈值微调；**也不再把「并集扩池」当微图主抬分刀**（与确认加成同属「词面不抢席」，期望值同类偏低）。
- **产品立场（接受）**：本温度计 claim 分布上，**活词面代价 ≈ −1.8pp vs 空 BM25 锚**；词面价值应另用**实体/符号夹具**或私有 Work 场景验收，不强迫 SciFact 微图超过 `99fce`。

### 6.4 M-D · 候选浅重排（条件触发 · 本轮不排期）

- 触发：结构刀 P1 后名次桶仍主残余，且有 displacement 观测。先修因后修果。

### 6.5 M-E · 可停环（**软递减 hint 已否决并回滚**）

- **已做并回滚**：同 Turn 连续 `search_sources` top-N path 重叠 → `hint` 劝 `read_file`（`SEARCH_SOURCES_DIMINISHING_HINT`）。  
- 跑次 `53864c3a`：nDCG@10 **0.819**（= `a823`）；分桶 **14/5/1**（与 `a823` 同形）；**q-1 仍 `search_cap`（n_search=3）**——软提示未压住打满硬帽。  
- **裁决**：本微图上**无行为增益、无 IR 增益** → 代码已撤；硬帽 `search_sources_max_per_turn` 保留为安全网。  
- **明确不再试（无新证据前）**：同假设的 tool-result 软停搜文案 / 重叠阈值微调。更强手段（契约级停搜、改 scenario）须另票且过 brief 契约门。

### 6.6 执行序（三次改道后）

