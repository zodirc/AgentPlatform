L1 与同轮修补

net_signal = composite + penalties（rewards 在 payload，不进 net）
同轮修补：仅过程 L0 或 length_short → propose_patch(repair_span)
  net 低只观测，不出 span；编辑札记在下一章
  repair_span 跟检测岛走（碎拍取最密岛，不升成最弱评分窗）
  默认不附平台 neighbor；碎拍且本 Work 有 local beats 时附本书自己的拍
  同岛：仅对上一次已生效的 old_text（相同或可见 overlap ≥12）停；下一岛仍 propose_patch
  无差 / 短对白仍在 → patch_island_untouched（不计 applied）
  预算（计 applied，不计提案）：每 key 2 / 章合计 3 / rewrite_window 仅小岛每章 1 / apply miss 连 2 次停
  宽窗或 rewrite 尽 → rewrite_policy=stop（长篇：章已落盘，窗留到下轮）
  hygiene：拒绝对白改旁白；小岛尽才 rewrite_window，禁止拿开篇整窗升级
  表面层六指标 post_turn 写 sidecar，Ops 页展示，不进同轮 tool_result
    ◆ 要点  同岛不停，模型会在同一 12 字里打转直到撞 max_steps。预算尽了必须停修，不要把开篇再 rewrite 一遍。
