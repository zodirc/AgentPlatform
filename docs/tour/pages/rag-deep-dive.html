  3. 11

    search_hybrid：Doc 车道与 Chunk 车道并行，超时保 chunk

    输入是步骤 10 的 query 和 over-fetch 后的 limit（店内 top_k = max(limit*4, 20)，精排开时再抬到 rerank pool）。判定：two_level_enabled 关则只跑 Chunk。开则两线程，预算约 0.3s。Chunk 同线程先后：HNSW ANN + GIN FTS；两路都有才 RRF（按位次），单路则那路当 pool；空则 []。Doc 只出 path：先 centroid 表 HNSW，空/失败/关表则宽 chunk ANN 按 path 去重。超时且 chunk 空会同步再跑一遍 Chunk。输出：doc_paths + 已 RRF/精排的 chunk_hits。下一步：图步 12 若精排未在 lane 内做完则 lexical；图步 13 用 path 加 doc_boost。

  5. 13

    merge_doc_and_chunk_hits：Doc 赢家 path 上的切块加 doc_boost

    输入：图步 11 的 doc_paths（可空）+ 图步 12 后的 chunk_hits + profile doc_boost（默认 0.35）。判定：chunk.path ∈ doc_paths → score += boost，进入 boosted 组；否则进 rest。两组各自按 score 降序，再 boosted + rest 拼接截断到 limit——不删除仅 chunk 命中项。doc_paths 空则原样截断。此步在 L2 之后，不再写入 record_ranked。输出：店内最终 ChunkHit[:limit] 交回工具层。下一步：图步 14 cover/tier/fallback。

    two_level.merge_doc_and_chunk_hits 
    def merge_doc_and_chunk_hits(*, doc_paths, chunk_hits, limit, doc_boost):
    if not chunk_hits: return []
    if not doc_paths: return chunk_hits[:limit]
    preferred = set(doc_paths)
    boosted, rest = [], []
    for hit in chunk_hits:
        if hit.path in preferred:
            boosted.append(ChunkHit(..., score=float(hit.score) + doc_boost))
        else:
            rest.append(hit)
    boosted.sort(key=lambda h: h.score, reverse=True)
    rest.sort(key=lambda h: h.score, reverse=True)
    return (boosted + rest)[:limit]
