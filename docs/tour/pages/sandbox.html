exec 沙箱与评测解题改道

审批通过只说明这次调用可以执行。可写路径和出网主机由沙箱再定：子进程对当前 Work 根可写，宿主机和 agent 服务的其余路径不在这个可写面里。执行请求走 SANDBOX_PLANE_URL 的 POST /internal/sandbox/exec，不进 Redis。调用方等的是这一次的退出码，队列里的消息可以晚到。产品命令在 bwrap 里 --unshare-net，注册表和 GitHub 经沙箱内 127.0.0.1:3128 出去；其它主机要在 egress_hosts 里点名再批。评测关掉这条代理。sandbox_relax 批准之后，网络才改为共享。

  • ◆ 要点 评测要求断网时必须使用 bwrap。工作区里的测试通过不算官方分数。

日常沙箱（平面内首次探测后 sticky）

编排 runtime ──HTTP──► sandbox 平面（SANDBOX_PLANE_URL）
  未配置平面 URL 时回退进程内 sandbox（兼容 monolith / 测试）

平面内选择顺序  Landlock → bwrap → off
  Landlock  Linux ≥5.13，ABI≥1；restrict_self 不可逆，探针在子进程做
            可写 jail = 当前 work_root（与 bwrap RW 面一致）；私有 tmpdir
            ABI≥4 且挂了 /egress 时，TCP 只允许连本机 3128
  bwrap     包装 argv；产品命令 --unshare-net，并绑定 /egress 代理
            评测：不启代理。sandbox_relax 批准后才 --share-net
  off       裸 shell；argv 仍先过路径软 jail（不得越出 Work 根）
  TOOL_SANDBOX=off|landlock|bwrap  破窗覆盖；off 每次调用都生效，自动探测结果 pin 在进程生命周期
  结果 dict 带 sandbox 后端标识，便于 Ops 判断「这步到底关在哪一层」
◆ 要点  Landlock 单独不能满足评测断网。deny_network 时必须 bwrap --unshare-net；没有 bwrap 就硬失败，禁止降级到 off。
◆ 要点  热路径是 HTTP；Redis Streams 只承载异步索引等，不承载 exec。

菱形：是否官方编码评测题

条件：Turn 带 ops_eval 标记 且 工作区存在实例标记文件

  是  pytest 后即使跟随 | tail：剥展示管道，完整 stdout/stderr（各截 32k 仅用于回传，解析走未截断全文）进该题 sweb.eval 镜像 /testbed
      python -c / 版本探测同样进镜像；默认复用该题容器，只增量同步改过的文件
      --network none
      禁止在裸 worktree 上 pip/uv install（SWE 环境是预拉镜像，不是现场装依赖）
      看板「SWE 评测环境就绪」= docker.sock + 镜像已拉 + 每张镜像 python/pytest//testbed 冒烟均通过
      缺镜像或冒烟失败 → 硬失败并写明原因；不得标成模型 resolve_rate=0
      ◆ 要点  工作区 pytest 绿不能当分数。Lite 每题环境不同；评委跑的是镜像。
