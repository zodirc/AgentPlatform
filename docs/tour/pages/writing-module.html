写作是十块叠在同一条 Engine 上，不是第二条循环

写作功能加在同一条 Engine 上。场景壳提供工具和提示，稿在 Work 上，写作规格进入 volatile，成稿工具负责写盘。L0 和交付门会拒绝调用或改写摘要。L1 分数附在 tool_result 上，奖励项只供观察。Engine 中不写 if scenario == "writing"。文件索引见 docs/writing-module.md。主链在上一页，评分在下一页。

  • ◆ 要点 L1 分数附在 tool_result 上，不直接改稿。L2 评委不进入产品 Turn。

十块

① 场景壳   writing.yaml · system.md · hooks（cards / focus / continuity / empty_transcript）
② 稿树     outline.md · volumes/ · chapters/ · drafts/manuscript.md · sources/cards · drafts/archive · .agent/work
③ 规格     book_scope × regime × work_mode × fragment × outline_phase × 章职（Writing spec ≤620 字）
④ 成稿工具 draft_section · update_outline · propose_patch · propose_book_candidates · export
           相位工具 author_state · reread_book · propose_retcon · editor_report · propose_chapter_openings
⑤ 过程门   L0 四类+篇幅 · 交付门只看篇幅 · patch 预算 2/3/1 · 卫生 · 叙事承诺配额
⑥ L1 评分  切窗 → 类原型 → net_signal（rewards 只观测）→ 仅 L0 / length_short 出 repair_span
⑦ 开篇点选 长篇未立定近池：只留 propose_book_candidates；awaiting_choice → TERMINATE
⑧ 检索特化 排除 seed/intel 与 archive；texture prior 1.4 / 0.35；每 Turn ≤3
⑨ 工作台   作品面板 / RAG 是否生效 / signals 弹层可钉档位；一键清空走 discard
⑩ 作品状态 story_state.json + editor_notes/ + author_notes.md + author_state + surface/
◆ 要点  外围 L2 narrative 与 Ops /ops/writing 只打分。C0 发散块恒 False。账户 writing_account_prefs 产品无入口、评分不读。

影响档（是否真的改产出）

硬   不经模型意愿：写盘、拒工具、停转、改摘要、改检索排序、注入 receipt
     draft_section / occupy=fresh / 短篇碎拍拒 append / 选书与等纲停转
     patch_auto_apply / 交付门只按篇幅改「已完成」/ texture 乘子 / 白名单无 write_file
     作者档不注入 L0 receipt；编辑相 editor_report 不改稿

软   进模型窗：system.md · [writing_context]（卡、spec、稿面、已选近池）· tool_result.repair_span
     模型可以不听，直到撞 max_steps=40。prefix cache：spec 不进 system

旁路 UI / golden 探针 / WritingSignalsModal。事件总线只有 writing_weak 等瘦字段

空转 L2 评委不进 Turn；账户 writing_account_prefs 产品无入口；C0 发散注入已关
◆ 要点  L1 net_signal 本身不改稿。仅过程 L0 或 length_short 往 tool_result 塞岛；硬停靠预算与工具拒绝。编辑札记在下一章。

接到 Engine 的点（不是新节点）

StartTurn     ScenarioRegistry.get(writing) 装工具/温度/hooks
相位          select_turn_tools：选书 → 等纲 → 修订/编辑 → 回读；命中即收白名单
组窗          volatile 做成 user 消息，前缀 [writing_context]（旁注：不是用户发言）
tool 完成后   attach_writing_signals → maybe_attach_prose_writing_signals
              严格档 note L0 pending；四类 receipt 互斥一张；作者档不注入
propose_patch writing 场景自动 apply，失败记 auto_apply_error
开篇工具      propose_book_candidates；awaiting_choice | stop_retry → TERMINATE
Turn 摘要     finalize_writing_turn_summary：【交付门】只列篇幅；compact 剥说明书
post_turn     continuity pending 卡 + local beats；story_state 机械半 + surface + editor_notes
◆ 要点  做成「自动再跑一轮润色」会把用户 pass 变成隐式流水线。每个 pass = 一次显式 Turn。

规格中的现行数字

book_scope  short 目标 2500 · single 3500 · 长篇章稿 3000–5000
            无名额章稿可见字 <3000 记 length_short；点名 N 字不足 85% 同样记
            「写一篇」优先于题材词；交付门：短篇/单篇看 length_short，长篇只挡本章 <800
regime      长篇默认 author，短篇/单篇永远 strict；句内覆盖 > 作品面板钉死 > 尺度默认
            作者档不注入 L0 receipt；story_state 进窗作者档 1200 / 严格档 900
work_mode   literary 默认 / web_serial；金标分库；学拍不搬核；权重不在设置页
fragment    评分切片不是工种；冷起步 mixed；mismatch 对齐申报 < 0.60 才记
卡片预算    合计 3600 · 单卡 2000 · style 1800 / 人物 1000 / 情节 600 / 一般 400
稿面        writing_work_surface_max_chars = 6000；选卡不看本轮 message（C3）
temperature 0.8 · max_steps 40 · patch 每 key 2 / 章 3 / rewrite_window 1 / miss 连 2 停

稿树（Work 根，不是 Session）

一本书在 book.py 中的库存：大纲、正文、卡、拍、归档
扔掉整本 discard：清用户稿与 .agent/work 侧车；不动 seed、资料库上传、会话
fresh：wants_new_piece 且 occupied → archive + unlink；不要提示用户先删文件
空工作区仍用 draft_section / update_outline 建文件；propose_patch 不能建新路径
◆ 要点  Session compact 不得拆散 Work。切会话 ≠ 换作品根。

无单独海报：主链在上一页，评分环在下一页。本页只回答「由几块组成、接到哪、哪一档真改稿」。
