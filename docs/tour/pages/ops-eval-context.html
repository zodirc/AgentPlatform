对照 idx 1：input = Is the ISR necessary for transgene reactivation?；answers = ["No, it is not necessary."]（context 约 45634 字符，不进评分器可见范围以外的 prompt）。预测 No → token 袋 {no} 对五词金标，P=1、R=1/5 → EM=0，F1=0.333。语义成立，EM 仍为零。idx 2 为 STM/STS 同义改写：EM=0，F1=0.8。

命中定义

尺子计算选取理由
规范化 小写、去冠词/标点、压空白；含 CJK 的金标按字 空白分词对中文无意义。金标列表永不改写。
EM 规范化后预测 等于 任一条 gold 得 1 v2 不做「gold 为 pred 子串即判对」（v1 会把带推理的长答判满分）。
F1 预测与 gold 的 token 袋重合；多条 gold 取最高 LongBench 官方 QA 指标。F1 高于 EM 是尺子形态，不必然表示「半对」。

禁止用第2轮入账事故值 0.4557 / 0.0000 验收后续改动。infra 失败剔除，不得记为模型零分。

审阅偏差。 短答案 QA 惩罚正确但措辞不同的回答（EM 尤甚）。n=60、每任务 head 切片，不得当作 LongBench 全文成绩。主指标不回答「是否读到相关段落」。
