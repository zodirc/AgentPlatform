命中定义

尺子单条 query选取理由
命中 融合排序中的 doc_id ∈ 该 query 的 qrels 且 rel>0 官方 IR 相关文档集合。不计终答是否提及金标标题；不计 read_file 是否打开金标文件。
Recall@k |Rk ∩ G| / |G|，再对 query 宏平均 R@100 为第一验收位：金标未入池时，nDCG@10 无诊断价值。召回未抬升前不开交叉编码器。
nDCG@k 按位次折现的增益 / 理想 DCG 同等召回下，金标位次越前越好。第2轮 BEIR 出现过 nDCG@1 升而 R@100 降。
MAP@k 各命中位置 precision 对 |G| 平均 惩罚金标散落在尾部。与 nDCG 一并观察排序，不单独作闸。

归因分桶：no_search 不是召回失败；query_drift（首次未复制官方 query）不是嵌入失败；infra 失败不得记为模型零分。

审阅偏差。 主指标不是 RAG-QA。多轮 RRF 抬高后轮改写才召回的文档，有利于 iterative search，也会掩盖首次检索质量。n=20 的 head 切片相对全集可易可难，不得外推全库。
