契约位置与组件地图

公开字段与版本以 packages/contracts 为准。改 REST 字段、事件 JSON Schema 或 DDL 须先改契约包，再改 api/web 派生类型与实现。导览里的数字以代码为准；图上的字过期时改说明，不改皮肤。

  • ◆ 要点 设计取舍：漏了会在服务里先发明字段、让 YAML 冒号炸掉 OpenAPI、或把只读 GET 当成开工

机器源

packages/contracts/
  openapi/public.yaml              对外 REST；description 含冒号必须加引号
                                   （否则 test_public_yaml_paths_exist_in_app 解析失败）
  schemas/events/envelope.json     SSE / 行存储 / 活流共用信封（0.3.13+）
    耐久：required 含 sequence≥1；additionalProperties false
    活流：live=true · sequence=null · live_seq≥1（Redis turn.live.*）
    stream_id 通常等于 turn_id
  schemas/events/types.json        事件枚举（phase0/1/2）
  schemas/events/payloads/*.json   分类型 payload；tool.completed.summary maxLength 4096
                                   turn.token / thinking.delta / section.draft.delta 的 delta ≤8192
  schemas/commands/                start_turn · approve · deny · cancel
  schemas/projections/             turn_view · session_view
  eval/ops_run_manifest.schema.json
  python/                          派生类型；api 测试须 overlay 本树，勿用缺文件的 stub 包

校验
  event_payload_validation 默认开（校验 payload，非整信封）
  高频 delta 默认轻量校验（R3）；event_payload_validation_strict_deltas 仅 CI
  delegate 摘要必须 clamp 到 4096，否则打破 tool.completed schema
◆ 要点  data: 是信封 JSON。耐久缺 sequence 无法续传；live 故意无 sequence，重连靠 view。

只读 vs 开工

不触发 Agent loop
  GET /turns/{id} · /view · /stream · GET /runs/{id}
  Sessions / Works / 健康检查
  SSE 挂看 ⊈ inflight

触发 loop
  POST /sessions/{id}/turns          → 入队 pending（202 ≠ accepted）
  POST …/approve-tool-call|deny|cancel → run_commands，达持约副本
